# uv Python container app

A UIless Python app that Kaithem runs as a command in a container.

1. Run the `sync` script once to install dependencies (or `sync-offline`
   if the network is unavailable).
2. Start the app.  Its output appears in the app console.
3. Run the `debug` script to start the debug adapter, then open the link
   shown in the UI to attach the text editor's debugger.
